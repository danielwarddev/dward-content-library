# Trigger Criteria

Create a markdown document when any of the following conditions are met:

1. **Numbered lists of ideas** — "X ideas," "X suggestions," "X examples," "X ways to..." (e.g., "10 blog post ideas," "5 ways to improve...")
2. **Resource lists** — websites, tools, resources, books, courses, etc.
3. **Comparisons** — comparing two or more concepts, tools, approaches, or ideas
4. **Pros/cons analysis** — evaluating advantages and disadvantages
5. **Multiple options** — presenting several alternatives for the user to evaluate
6. **Research summaries** — findings that include multiple data points
7. **Brainstorming sessions** — any creative ideation producing multiple outputs
8. **Step-by-step guides** — multi-step processes or tutorials with substantial content
9. **Large amounts of content** — any response with a lot of output to parse

## Thresholds

- **5 or more distinct items** in a list
- Response longer than **~500 words**
- Content the user would likely **reference later**
- Content involving **evaluation or decision-making**

## When NOT to Create a Document

- Simple, short answers (fewer than 5 items, under ~300 words)
- Single direct answers to questions
- Code snippets or quick fixes
- Conversational responses
- When the user explicitly asks for an inline response only

## Why This Exists

- The user gets **more comprehensive information**, since the document format allows richer detail
- Content is **persistent and searchable** in the workspace
- The user can **review and edit** it later
- Enables **richer formatting** like tables and detailed subsections
- Reduces **context window pressure** in long conversations
