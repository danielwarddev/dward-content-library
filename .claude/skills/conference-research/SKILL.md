# Conference Research

Research a conference to understand what kinds of talks get accepted, so a submission can be positioned well.

## When to Use

- Before writing or refining an abstract for a specific conference
- Deciding whether a talk idea fits a particular conference
- Understanding a conference's audience and typical content
- Comparing conferences to decide where to submit

## Start Here

Ask the user, if not already provided:

> "Which conference are you targeting? (If you have a link to the conference or its past programs, that helps!)"

Then work through the five steps below, reading the reference for each as you get to it.

1. Find past programs → [references/finding-programs.md](references/finding-programs.md)
2. Analyze patterns in accepted talks → [references/analyzing-patterns.md](references/analyzing-patterns.md)
3. Generate positioning recommendations → [references/analyzing-patterns.md](references/analyzing-patterns.md)
4. Summarize using the standard format → [references/output-format.md](references/output-format.md)
5. Save findings to `conferences/[conference-name]-[year].md` → [references/output-format.md](references/output-format.md)
