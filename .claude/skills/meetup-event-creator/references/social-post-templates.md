# Social Post Templates

## Platform Limits

| Platform | Limit |
| -------- | ----- |
| Twitter/X | 280 characters |
| Bluesky | 300 characters |
| LinkedIn | No limit |

## Cross-Platform Notes

- Twitter/X and Bluesky posts are typically identical except for account tagging.
- Twitter/X uses `@handles`, such as `@GitHubCopilot`.
- Bluesky uses handles such as `@github.bsky.social`.
- LinkedIn uses full display names such as `GitHub Copilot`, not handles.
- LinkedIn may include slightly more context because it has no character limit.
