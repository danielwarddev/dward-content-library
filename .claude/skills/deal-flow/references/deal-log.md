# Deal Log

Track every live opportunity. One file per deal, kept in
`project-ideas/playbooks/side-income/deals/`, named `company-name.md`.

The point is not administration — it's that at 2 hrs/night, deals die from being forgotten rather than
from being lost.

## Per-Deal Template

```markdown
# [Company] — [Contact Name]

**Status:** Probative | Qualifying | Value | Closing | Won | Lost | Parked
**Opened:** YYYY-MM-DD
**Last touch:** YYYY-MM-DD
**Next action:** [one concrete action] by YYYY-MM-DD

## Who
- Contact, role, how I know them
- Company, team size
- Decision maker (if different)

## Qualifying
- Trigger event (licenses bought when?):
- Problem, in their words:
- Urgency / deadline:
- Authority:
- Employer conflict checked: yes/no

## Value
- Desired future state, in their words:
- What it's worth (their numbers):
- Cost of inaction:
- Budget range signalled:

## Offer
- Option presented:
- Price:
- Sent on:

## Log
| Date | What happened | What I learned |
| ---- | ------------- | -------------- |
```

## Pipeline Rules

- **Every deal has a dated next action.** No next action means it isn't a deal.
- **Review weekly.** Ten minutes. Anything untouched for 30 days moves to Parked or Lost.
- **Parked is honest; "still following up" is not.**
- **Log the reason on every loss.** Patterns across three losses are worth more than any single deal.

## Rollup

| Company | Contact | Status | Next action | Due |

## Leading Indicators

Sales lag by months. Track activity, not just outcomes:

| Metric | Target |
| ------ | ------ |
| Referral asks sent | ≥8/month after each user group |
| Decision-maker names obtained | growing |
| Qualifying conversations held | ≥2/month |
| Value conversations held | ≥1/month |
| Proposals sent | — |

If proposals are zero but qualifying conversations are healthy, the problem is in the Value
conversation. If qualifying conversations are zero, the problem is the ask — not the offer.
