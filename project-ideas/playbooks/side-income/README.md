# Side Income

Figuring out how to earn ~$1k/mo on the side, using an existing .NET/AI expertise base (Microsoft MVP,
user group lead, blog, conference speaker) and ~2 hours per night.

**The short version:** sell an already-built half-day GitHub Copilot workshop to reach the number, treat
solo building as the long-term track it funds, and keep game dev as a hobby that produces content rather
than income.
