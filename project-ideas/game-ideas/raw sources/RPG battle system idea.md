You have a turn 1 set of skills/spells, turn 2 set, turn 3, etc. Each set can take any spell, but depending on which set, will take a more powerful tier of it. A tier can also cast any lower tier version of the spell

Example:

Class: Healer

Set layout:

Skill 1: Heal/Support

Skill 2: Buff

Skill 3: Damage/Condition

Heal skill:

T1: Heal 1 target a low/moderate amount

T2: Heal all targets a low amount

T3: Heal all targets a high amount

T4: Fully heal a target

T5: Full heal all targets

So you can either cure conditions or heal on turn 1, but not both – but you can do the other on turn 2. This would probably work best with a battle system that fully heals after each battle.
