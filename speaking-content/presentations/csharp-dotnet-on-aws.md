# Breaking the Prime Directive - Using C# for IaC to Put .NET on AWS

## Description

.NET and AWS are seemingly alien worlds to each other for many developers. Because of that, though, the perks of using .NET on AWS are also not as well-known. What are the pros and cons of breaking the Prime Directive and connecting these alien worlds together?

In addition, this presentation will address how to deploy .NET apps on AWS. It's fairly common now for teams to be in charge of deploying their own architecture using infrastructure as code (IaC). While this is a good practice, it also adds knowledge requirements to learn the IaC language and ecosystem. What if .NET teams could write IaC in C#, which they already excel in and use everyday?

This talk will cover those very things. It will go over some benefits to using .NET on AWS, and why you might choose to go that route. Then, it will demonstrate how to easily deploy a .NET app to AWS using the AWS CDK for C# to both define and deploy an AWS infrastructure using only C# code, and how to use that infrastructure to deploy a C# app.
