# GitHub Copilot for Teams: A Hands-On Training Program

**From AI-curious to AI-effective in 6 weeks.**

---

## The Problem

Most developers either underuse GitHub Copilot — treating it as fancy autocomplete — or over-rely on it, accepting AI-generated code without understanding or verifying it. Both leave value on the table and introduce risk. Teams need structured guidance to adopt AI-assisted development confidently and responsibly.

## The Program

A **6-week, hands-on training program** that takes developers from zero Copilot experience to using it effectively in their daily work. Each session builds on the last, with practice between sessions so participants develop real muscle memory — not just awareness.

**12 sessions × 1.5 hours** | 2 sessions/week | Remote or in-person | Copilot Business

### What Makes This Different

- **Not a one-day fire hose.** Spaced over weeks, participants practice between sessions and come back with real questions.
- **Not just features — workflows.** Every session teaches *when* and *why*, not just *how*.
- **Responsible AI habits from day one.** Five core principles reinforced in every session: trust but verify, work in small batches, verify loops, don't vibe code, AI is a tool.

## What's Covered

| Week | Focus | Sessions |
|------|-------|----------|
| **1** | **Foundations** | AI fundamentals, Copilot setup, UI tour, inline completions, chat basics |
| **2** | **Prompting & Context** | Effective prompting techniques, context windows, copilot instructions, @workspace |
| **3** | **Modes & Agent Mastery** | Ask / Edit / Agent modes, Agent deep dive, working in small batches, verify loops |
| **4** | **Customization** | MCP servers, custom prompts (.prompt.md), custom agents, agent skills |
| **5** | **Advanced Workflows** | Research-Plan-Implement (RPI), agent orchestration, responsible AI, debugging |
| **6** | **Enterprise & Integration** | Copilot CLI, Coding Agent, Code Review, Hooks, full workflow integration |
| **Bonus** | **Capstone Project** | Build a real project end-to-end using all techniques (2.5–3 hours) |

## Session Format

Every session follows the same structure so participants know what to expect:

| | |
|---|---|
| **Recap & Homework Review** (10 min) | Review last session, share experiences |
| **Teaching & Live Demo** (35 min) | New concepts with real demonstrations |
| **Guided Exercise** (25 min) | Hands-on practice with instructor support |
| **Independent Practice** (15 min) | Apply skills on their own |
| **Wrap-up & Homework** (5 min) | Key takeaways + homework (videos to watch, tasks to finish) |
