# The Copilot Gap: What You're Missing With AI Coding Assistants

## Description

Many developers fall into two camps with GitHub Copilot: using it as a fancy autocomplete or as a magic wand that tries to implement everything within a few prompts.

This approach often leads teams to spend more time on tasks than they would without AI, either because AI wasn't the best tool for the job or because it didn't receive enough context.

Studies show Copilot increases productivity and lowers frustration, but also that it can end up lowering critical thinking and producing less secure code. How can we make sure we're on the former side of that?

This session will go over the practical tooling available in GitHub Copilot, how attendees can use these features effectively to get the results they want, and the right and wrong times to use AI.
