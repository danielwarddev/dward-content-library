# Getting Started With AI For .NET Devs With Agent Framework

## Description

AI has remained a popular topic with continued investment from many enterprises. However, as a developer, it's easy to be unsure about how to get started with AI, or how it even fits into your existing workflow. Without familiarity about these new concepts, teams now risk missing out on powerful tools that are changing the way we create software.

Attendees will be introduced, from a zero-knowledge standpoint, to AI concepts such as LLMs and AI agents. In particular, this talk will be given from a .NET perspective, and will go over Microsoft Agent Framework, Microsoft's open-source SDK for building AI-powered applications.

This session will go over what Microsoft Agent Framework is, why you might want to use it, and show a C# coding demo with it, so that attendees can leave with a working knowledge about how to create AI-powered apps themselves.
