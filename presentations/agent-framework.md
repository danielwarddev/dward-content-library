# AI Agents in Python and C#: Getting Started with Agent Framework

## Description

If you've ever been curious about building real, production-ready AI agents, this session is for you! 

Microsoft Agent Framework, an open-source SDK in Python and C#, provides everything you need to create robust agents, from tool calling to multi-agent orchestration.

This session will cover what Agent Framework is, what makes it powerful, and how to build your own AI agents from scratch. A live demo will show how to create an agent, call tools, and orchestrate multiple agents together.

Whether you're a solo dev or on a team at an enterprise, you'll leave with working knowledge of how to get started creating agents yourself. Come ready to see what's possible!

## Organizer notes

"Agent" is a very common term with AI right now, but the vast majority of developers probably haven't tried to make their own agents yet, or know why they might want to over just creating prompt chains and bash scripts. I think this could be a neat opportunity to show how to use a fleshed-out, open-source framework for creating them!

Talk outline:
- Concepts - what's an agent? Tool calling, memory, reasoning
- Why agents matter
- Microsoft Agent Framework - what it is, why to use it
- Coding demo - basic LLM call, tool calling, watch the agent reason and choose tools, watch the agent complete a real task, multi-agent orchestration
- Takeaways - resources, next steps, things to try

The lightning talk version of this talk would be a quick coding demo of Microsoft Agent Framework's features and what it looks like to make your own, along with running one.
