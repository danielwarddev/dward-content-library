# The Cloud & AI Summit 2026

## Conference Details

-   **Event:** The Cloud & AI Summit 2026 (formerly dev up)
-   **Dates:** September 30 - October 2, 2026 (3 full days)
-   **Location:** Ameristar Casino and Convention Center, St. Charles, Missouri
-   **Website:** https://www.cloudandaisummit.com
-   **CFP Link:** https://sessionize.com/thecloudandaisummit2026
-   **CFP Deadline:** February 28, 2026
-   **Speaker notifications:** By April 1, 2026

## Speaker Benefits

-   ✅ Full 3-day conference ticket
-   ✅ Hotel (3 nights: Sep 29 - Oct 2)
-   ✅ Travel stipend for out-of-town speakers
-   ✅ Uber code for local transportation
-   ✅ Speaker appreciation event (evening of Sep 29)

**Note:** Multi-speaker sessions only get benefits for one presenter.

## Conference Profile

-   **Focus:** Microsoft Azure and AI technologies (sharp focus after rebrand)
-   **History:** 18 years as "dev up" — now rebranded with Azure/AI focus
-   **Size/vibe:** Regional midwest conference, community-driven, non-profit
-   **Audience:** St. Louis area and midwest developer community

## ⚠️ KEY CHANGES FOR 2026

-   **IN PERSON ONLY** — All speakers must present on-site
-   **1.5 hour sessions** — Longer format for deeper content
-   **Fewer session slots** — More competitive selection
-   **Three full days** — No separate pre-con workshop day
-   **Opening keynote returns**

## Content Tracks

### Pro Code

C#, .NET, ASP.NET Core, Angular, React, Blazor, modern web development patterns, GitHub Copilot, Visual Studio, and best practices for building enterprise applications.

### Low Code

Microsoft Power Platform including Power Apps, Power Automate, Power Pages, Dynamics 365, Dataverse, Azure Automation, Logic Apps, strategies for citizen developer enablement and governance.

### Cloud Operations

Azure infrastructure management, Azure Arc, monitoring and observability, cost optimization, landing zones, governance, identity management, and IT Pro focused administration topics.

### AI

Azure OpenAI Service, Azure AI Foundry, Copilot Studio, building AI agents, Microsoft Agent Framework, Model Context Protocol (MCP), prompt engineering, responsible AI practices, and integrating AI into your applications.

### Data and Analytics

Microsoft Fabric, Power BI, SQL Server, Cosmos DB, data modeling, data engineering, real-time analytics, and building modern data platforms.

### Security

Microsoft Defender, Microsoft Sentinel, Intune, Purview, Entra ID, Zero Trust architecture, compliance, threat protection, and securing your cloud and hybrid environments.

### DevOps

Azure DevOps, GitHub Actions, CI/CD pipelines, Infrastructure as Code, Terraform, Bicep, containerization, Kubernetes, agile practices, and platform engineering.

### 💡 SUBMISSION STRATEGY

**Key insight:** They encourage multiple submissions and may ask speakers to present more than one session:

> "Typically, when a speaker is capable of presenting great content on multiple topics, their likelihood of being selected is greatly increased."

**Recommended approach:**

1. Submit **Agent Framework** to AI track (perfect fit)
2. Submit **Copilot Gap** to AI or Pro Code
3. Submit **TestContainers** to Pro Code
4. Submit **Pulumi** to DevOps

Indicate in your submission that you're open to presenting multiple times!
