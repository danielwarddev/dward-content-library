## Strategic Notes

- **Low barrier to entry** — community code camp, likely high acceptance rate for quality proposals
- **75-minute sessions** — longer than typical conference talks; plan for more depth or live demos
- **Travel cost consideration** — no speaker perks, so you'd be covering travel to Boise, ID yourself
- **Good testing ground** — code camps are excellent for testing new talks in a low-pressure environment
- **Regional networking** — opportunity to connect with Pacific Northwest dev community
- **Submit multiple** — code camps often accept multiple talks from the same speaker
- **CFP closes March 14** — 25 days from today, plenty of time
